# GoodWall

A minimalist static web app that delivers a glowing "Did You Know?" trivia experience. The page showcases a neon-inspired UI with a single button that reveals a new random fact on each click.

## Features

- Static HTML/CSS/JavaScript app
- Responsive dark glassmorphism design
- Hover and click button interactions
- Random fact rotation with a simple fade animation

## Files

- `index.html` — the complete app, including markup, styling, and client-side scripting

## Usage

1. Open `index.html` in a browser.
2. Click the **Reveal Another Wonder** button.
3. Enjoy a new fun fact on every click.

## Notes

- No build step or dependencies required.
- Works as a standalone static page.

## Customize

- Edit the `facts` array in `index.html` to add or replace trivia.
- Modify the CSS in the `<style>` block to adjust visual theme, spacing, or colors.
